# Pattern library

Every reusable section layout, so 75 pages stay one family. Page agents reuse these first ("Option A" in the layout step).
Source markup: `theme/sections-reference.html` (theme v1 homepage, each section preceded by its PATTERN comment).
New patterns are added only by golden pages and promoted by the orchestrator after review (CSS moves into `theme/patterns.css`).
Golden-page markup: `theme/components.html` (index in `theme/components.md`). Rows marked "01" or "09" were promoted from the pilot goldens on 12-Oct-2026; rows marked "01 v3" or "09 v3" from the v3 rebuild of the same goldens (curated 12-Oct-2026). Their CSS is in `theme/patterns.css`, not in the pages. Start new pages from the v3 rows; rows marked "legacy" stay only until 10 is rebuilt on v3.

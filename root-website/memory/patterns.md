# Pattern library

Every reusable section layout, so 75 pages stay one family. Page agents reuse these first ("Option A" in the layout step).
Source markup: `theme/sections-reference.html` (theme v1 homepage, each section preceded by its PATTERN comment).
New patterns are added only by golden pages and promoted by the orchestrator after review (CSS moves into `theme/patterns.css`).
Golden-page markup: `theme/components.html` (index in `theme/components.md`). Rows marked "01" or "09" were promoted from the pilot goldens on 12-Oct-2026; rows marked "01 v3" or "09 v3" from the v3 rebuild of the same goldens (curated 12-Oct-2026); rows marked "W1" with a page number (03, 07, 17, 29, 42, 57, 62, 65) from the Wave 1 goldens (curated 12-Oct-2026, one kit per template). Their CSS is in `theme/patterns.css`, not in the pages. Start new pages from the v3 and W1 rows; rows marked "legacy" are used by no page since 10 was rebuilt on v3. Template rules (`.tpl-x` body class) need no page CSS: a derivative inherits them by its template.
